A program that writes one original one-line dad joke to /output/entry.txt for make.fun's "The One-Liner Groan-Off" bounty — a single original dad joke, at most 140 characters, judged pairwise on how well it lands as a dad joke, how fast the punchline arrives, how fresh it is, how tight the wording is, and how good the groan is.

## Run it

```sh
node main.ts
```
